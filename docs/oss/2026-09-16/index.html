Problem it solves / who it's for

Hands-on developers who run Claude Code, Codex, Cursor, Copilot, OpenCode, Goose, etc. daily and burn tokens on repetitive tool dumps, logs, JSON, and RAG chunks. Headroom sits between the agent and the provider: same answers (per their evals), fewer tokens, originals kept locally for on-demand retrieve. Also useful if you juggle several agents and want shared cross-agent memory / failure→doc learning (headroom learn).

Skip if you only use one provider’s native compaction, don’t need cross-agent memory, or can’t run a local process/proxy.

Key capabilities & usage (from full README)

  • What it compresses: “tool outputs, logs, RAG chunks, files, and conversation history — before it reaches the LLM.” Compression “runs on your machine; no prompt or file content is sent anywhere to be compressed.”
  • Surfaces:
  • Library: compress(messages) (Python / TS)
  • Proxy: headroom proxy --port 8787 (zero code changes)
  • Agent wrap: headroom wrap claude|codex|grok|copilot|cursor|aider|… (+ headroom unwrap)
  • MCP: headroom_compress, headroom_retrieve, headroom_stats
  • Cross-agent memory; headroom learn mines failed sessions into CLAUDE.md / AGENTS.md / etc.
  • Optional output token reduction (verbosity steering + effort routing) via HEADROOM_OUTPUT_SHAPER=1
  • Pipeline (paraphrased): CacheAligner → ContentRouter → SmartCrusher (JSON) / CodeCompressor (AST) / Kompress-v2-base (text, HF model) → CCR (local originals + retrieve tool). Live-zone compression keeps provider KV-cache prefixes stable.
  • Claimed savings (README proof table, seeded offline): e.g. SRE incident log 55,957→24,340 (~57%); code search ~21%; JSON/logs can hit much higher; latency “well under a millisecond” on their benches.
  • Integrations listed: Anthropic/OpenAI SDKs, Vercel AI SDK middleware, LiteLLM callback, LangChain, Agno, Strands, ASGI middleware, MCP.
  • Telemetry caveat (README): anonymous beacon on by default (ratios/counters/model IDs only; no prompts); disable with HEADROOM_BEACON=off, DO_NOT_TRACK=1, or --offline.

Quick start (from README)

  1. Install CLI: uv tool install --python 3.13 "headroom-ai[all]" (or pip install "headroom-ai[all]"). Prefer 3.13 for LiteLLM dollar-savings tile (3.14+ breaks that dependency).
  2. Wrap an agent or start proxy: headroom wrap claude or headroom proxy --port 8787 or headroom deploy.
  3. Verify: headroom doctor then headroom perf / headroom dashboard.

Inline Python sketch from README: from headroom import compress → compress(messages, model="gpt-4o") → pass result.messages to the provider client.

Risks / caveats

  • Release lag: tagged/PyPI 0.37.0 is ~3 weeks behind main; some Sep fixes (Claude Code 2.x env, CCR headers) may not be in the wheel yet — check open issues #3595–#3597 if wrapping Claude Code 2.x.
  • Platform friction: README notes Intel macOS may need Docker until native wheels land; ONNX paths need AVX2 on x86 (falls back otherwise); open #3604 reports MPS abort on macOS 26 during embedder load.
  • Telemetry default-on (disable as above).
  • Savings vary: prose / already-dense / short chats compress little; payoff is long agent sessions with heavy tool I/O.
  • Large open-PR queue (~332) — vibrant but noisy contribution surface.
