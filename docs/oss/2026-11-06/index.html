知了 Cicada：开会直播都能实时双语字幕、同传和 AI 纪要，四个平台开箱就用

为什么今天值得试： 11 月 1 日开源，五天近 1500 星、269 fork；北京时间今早 03:58 刚发 v1.3.0，一口气补上 Intel Mac、会议室+线上同时听、自建 ASR 等硬需求。Zoom / 飞书 / 腾讯会议 / YouTube / X Spaces 都能听，不用往会里塞机器人。

仓库：wquguru/cicada · 官网：cicada.indaloop.app

它解决什么问题 / 适合谁

跨国开会或听英文直播时，既要听懂、又要记要点、有时还要开口回一句。市面上多数工具要么要往会里塞机器人，要么只做单一平台。知了直接读系统声音（或会议室麦克风），对方无感；边听边出双语字幕和结构化纪要（总结、议题、结论、待办、鱼骨图、人名术语表），按住说话键还能同声传译。

适合：经常开中英混合会、听外文直播、需要会后可搜索记录的个人和团队。Apple 芯片 Mac 上基础字幕/翻译可不填 key；要实时纪要、声音克隆等再配 Ling 或其他兼容服务。

从 README 读到的要点

  • 四端统一： Mac（14.4+）、Windows 10 2004+、Ubuntu 22.04/24.04、Android 10+，同一版本号和同一套会议记录格式；安装包在官网与 Releases，带 checksums.txt。
  • 听哪里可选： 「电脑」「会议室」「电脑和会议室」（混合会，各认各的语言，回声消除避免重复记）。字幕条只在有人说话时出现，划过会变透明。
  • 同声传译： Mac 上按住右 ⌥（Windows 右 Ctrl）说话，对方在会议里直接听到译文；可装 BlackHole / VB-Cable 虚拟麦；有 Ling key 可克隆自己的声音。
  • 隐私取向： Apple 芯片 Mac 上采集、语言/语音识别、录音默认本机；不填 key 也能用字幕、翻译、记录和基础同传。应用无埋点、无自建服务器；纪要窗默认避开屏幕共享。
  • 可换模型： 默认推 Ling（蚂蚁）；设置里可换 OpenRouter、ZenMux、OpenAI 或任意 OpenAI 兼容 / 本机 Ollama、vLLM 等，翻译、纪要、TTS、ASR 可分服务配置。
  • 会后能力： 本机存双语文字、纪要和录音；可按声纹区分说话人；导出 Markdown / Word / SRT；也可导入已有录音视频做离线转写。

近期活跃证据

  • Issues： 共约 11 个 Issue，开放约 5–6 个；维护者对 macOS 版本、会议室收音、标题编辑等反馈多在当天回复，并在后续版本落地（如 1.1.0 加会议室模式、降到 macOS 14.4）。
  • Release： 五天发了 5 个正式版：v1.0.0（11-03）→ 今早 v1.3.0（Intel Mac、Room/Computer+Room、自建识别服务、长会纪要更稳等）。
  • 提交： 主分支约 411 次提交（作者 wquguru 约 409），今天上午北京时间仍在修 Android/Linux/Windows 短句与噪音误触发等问题。

怎么快速上手

  1. 打开 下载页 或 Releases，按平台装（Apple 芯片选对应 DMG；Windows 装完跟引导；Linux 解压跑 install.sh；Android 装 APK）。
  2. 首次引导里开录音权限，听一段示例会议看双语字幕；需要纪要/同传再粘贴 Ling 或其他 AI 服务的 key。
  3. 开会时点开始听，按 ⌃⌥S 在纪要窗 / 字幕条间切换；要开口翻译再装虚拟麦并按住说话键。

风险与注意

  • 未公证 / 未代码签名： Mac 首次可能要在「隐私与安全性」里点仍要打开；Windows 可能被 SmartScreen 拦截。路线图里有正式签名与公证。
  • 平台能力差一截： 完整本机识别主要在 Apple 芯片 Mac；Intel / Windows / Linux / Android 听对方一般要云端 key。Linux 纪要窗躲不开屏幕共享。Android 录不到微信等受保护通话，需外放改「面对面」。
  • 个人发言还不完整： 目前记录里「你」主要是按住说话键说的话；持续听麦克风记你的自由发言还在路线图。
  • 早期单人主力： 贡献几乎全是作者，迭代极快，行为可能周周变；开 Issue 反馈质量不错，但开放 bug（如识别不准、采样率不一致崩溃）仍在跟。
