模型本地推理RAG离线知识库

Lastbook：把手册、视频、百科、离线地图和本地 AI 装进一台电脑，断网也能查「该怎么办」

为什么今天值得试： 大多数「本地 AI 知识库」要你自己找资料、切块、建索引。Lastbook 直接给一套整理好的离线求生/重建资料库（手册 PDF、教学视频、医学与 Appropedia 等离线百科、离线地图），再加一个可选的本机模型做带页码引用的问答，装好以后完全离线。北京时间 11-23 09:45 刚发 v1.1.16，第一次加入简体中文界面（社区贡献 #413），Mac/Windows/Ubuntu 都有签名安装包，下载即用。

  • 仓库：https://github.com/Immortal-Protocols/lastbook
  • 官网：https://lastbook.org
  • 许可证：MIT（自身代码与文档；资料、模型、地图各有各的许可）；主语言 Python；2953★ / 363 fork；最新 v1.1.16（2026-11-23 09:45 北京时间）
  • 2026-11-13 07:49 北京时间建库，组织 Immortal-Protocols，社区共建

解决什么问题、适合谁

  • 想在停电、断网、灾害时还能查到急救、净水、供电、种植、维修等实用资料的家庭和应急准备者
  • 想看「离线 RAG + 本地小模型」怎么做成普通人能用的桌面产品的开发者：引用校验、按机器内存判断模型能否运行、无端口桥接、下载白名单，这些工程细节都在代码里
  • 偏远地区、船上、野外基地等网络不稳定的场景，也可以用它的「图书馆服务器」模式给同一 Wi-Fi 下的手机共享

README 里的关键能力

  • 先给指南： content/topics/ 里是策展人写的短指南，按紧急程度组织，每条都指向库里真实的页码；content/gaps.json 还写明「找过但没找到」的资料
  • 完整资料库： 手册与 PDF（可整本阅读）、视频、离线百科（ZIM 文件），全库关键词搜索，Windows 上另有语义搜索（bge-small-en-v1.5 ONNX）
  • 离线地图： 世界和美国底图，加安装时选定的一个美国州的详细地图（街道、建筑、地形、水源、救助点），州内地址可离线查找；由用户自己选州，程序不探测位置
  • 可选本地 AI： 用 Gemma 4 26B A4B（Unsloth Q4_K_M，约 17 GB，约需 18 GB 内存），运行器是项目自己在 llama.cpp b12032 上写的 lastbook-llm（Mac 用 Metal，Windows/Linux 用 Vulkan 并可回退 CPU）；回答引用库内页面并做引用检查，不装模型时 Chat 也能找到对应页面。安装程序会先测机器是否装得下，装不下会用大白话说明原因
  • 网络与隐私边界写得很细： 桌面版不开任何端口（窗口与引擎走内存桥）；只有两种联网——用户手动开始的下载和手动点的「检查更新」，都走同一个模块，只连白名单主机的 443 端口，只信任内置的 11 个根证书，每个文件按清单 SHA-256 校验；无遥测、无账号、无定时联网
  • 资料包： Small（约 7.7 GB）、Medium（约 67.5 GB）、All（约 388 GB），也可以导入已有的资料文件夹或 zip；更新时新数据在旁边解包校验后再一次性切换，失败不会弄坏旧库

快速上手

  1. 到 https://lastbook.org/download/ 下载对应安装包（Mac 需 Apple Silicon + macOS 14；Windows 10+ 64 位；Ubuntu 24.04/26.04 用 sudo apt install ./Lastbook_1.1.16_amd64.deb），可对照官网的 SHA-256 校验
  2. 首次运行的安装向导里先选 Small 资料包试用，语言选简体中文（安装向导里或「Settings → Library and local AI」）；内存够的话勾选本地 AI（另加约 17 GB 下载）。资料库可以放到别的盘
  3. 下载完成后断网打开 Videos / Map / Chat，用英文提问，例如 "how to purify water without power"，看回答引用的页码是否对得上原文；想在局域网分享给手机，可以从源码用 LASTBOOK_DATA=/path/to/LastbookData python3 server.py 起服务

风险与注意点

  • 内容几乎全是英文、偏美国： 中文只翻译了界面，资料和 Chat 指南仍是英文；详细地图和地址搜索只有美国各州（非美国地图在 #23 跟踪），向导目前要求选一个美国州（跳过选项还在审核）
  • 体积和硬件门槛： Small 也要约 7.7 GB，本地 AI 再加约 17 GB 下载、约 18 GB 内存；Linux 只在 WSL2 上的 Ubuntu 测过，原生 Linux GPU 性能未验证；Mac 只支持 Apple Silicon；iPad 版只有源码
  • 急救类内容别全信： 搜索把问题导向错误指南的 bug 近几天还在修（如 #284 搜「stroke」打开中暑、#307「passed out」打开停电指南），真正紧急时请以当地急救电话为准
  • 项目很新、PR 积压： 建库 10 天，6 天发 6 版；135 个 PR 待审；有用户直言维护者回复像 AI 写的（#270）
  • 许可要分开看： MIT 只覆盖项目自身代码；资料包里的手册、视频、百科各有各的条款，分发的安装包还含 GPL 组件（python-libzim、libzim）
