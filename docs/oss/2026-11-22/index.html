Lot Map：在 Claude Code 旁边开一张「实时地图」，看清 Agent 每一步在干什么

为什么今天值得试： Claude Code 跑长任务时，你通常只能盯着一串工具调用滚屏。Lot Map 是一个 Claude Code 插件（mod），在对话旁的面板里画一张活地图：每次工具调用、模型步骤、hook、skill 都会从中心向对应站点（文件、Shell、网络、浏览器、记忆、子 Agent……）飞出一个脉冲，出错/被拒变红，上下文窗口占用画成中心的圆环。北京时间 11-22 02:50 刚发 v0.13.1（加越南语），前一版 v0.13.0 是一轮安全审查后的修复，一条命令就能装上试。

  • 仓库：https://github.com/alexeyw/lot-map
  • 在线演示（浏览器里回放同一套绘图代码）：https://alexeyw.github.io/lot-map/
  • 许可证：MIT；主语言 TypeScript；1106★ / 119 fork；最新 v0.13.1（2026-11-22 02:50 北京时间）
  • 2026-11-10 03:13 北京时间建库，作者 alexeyw

解决什么问题、适合谁

  • 每天用 Claude Code（终端、桌面 App 或 VS Code 扩展）跑长任务、开子 Agent、接了不少 MCP 的人，想一眼看出「它现在在读文件、跑命令还是在联网」
  • 想知道上下文快满了、哪类调用最吃 token、哪个 hook 拦了调用的人
  • 关心可观测性但不想把会话数据发到第三方服务的人：插件只在本机跑、不发网络请求

README 里的关键能力

  • 十个站点： You / Model / Memory / Files / Shell / Network / Browser / Agents / Skills / Hooks。Shell 命令按命令名归类：cat、grep、sed 这类算 Files，curl、gh、git push、npm install 算 Network；能看穿 sudo、env、xargs、bash -c、循环和条件里的命令，Windows 下 PowerShell 同样处理
  • 读图： 路线线条显示最近经过的站点顺序；越常用的站点辐条越粗；运行中的调用有内外两圈「时钟指针」（1 分钟/10 分钟一圈）；并发调用标 ×3；后台任务、子 Agent 一直亮到结束；模型切换会在列表里记一行如 opus 5.5 → fable 5.2；中心圆环是上下文占用，70% 变琥珀色、90% 变红
  • 每次调用吃了多少上下文（contextCost）： 每行显示该调用让上下文大约涨了多少 token（如 85 ms +42k），站点累计（如 9 · 180k）；是估算，晚一步显示，子 Agent 的调用没有数字
  • 到处都能看： 桌面 App 面板、VS Code（有缩放/隐藏按钮）、终端；终端默认只显示文字列表，可设 terminalView 为 picture（kitty、Ghostty、iTerm2 3.7.8+ 显示图片）或 braille（盲文点阵，Windows Terminal 和大多数 Linux 终端可用）
  • 可配置： 界面语言（en/ru/es/fr/de/it/pt/vi，暂无中文）、主题和自定义配色、memoryServers/memoryCommands 把自己的记忆 MCP 或脚本算到 Memory 站、serverStations/commandStations 把某个 MCP 或命令放到指定站点、openAtStart 关掉自动弹出
  • 隐私边界写得很清楚： 插件拿得到每次调用的完整输入，但只取名字——文件只显示路径最后两段、网址只显示 host、Shell 显示 Claude 写的描述或命令名、搜索不显示关键词、记忆不显示内容；不读文件、不起进程、不调模型、不往对话里加东西；hook 原样透传，不改任何输入输出和权限决定。PRIVACY.md 和 PRINCIPLES.md 里每一条都配了对应的测试

近期活跃证据

  • Release： 11-13 00:42 北京时间的 v0.5.3 起已发 11 个 Release，到 11-22 02:50 的 v0.13.1。v0.13.0（11-21 12:32）来自对 0.12.1 的安全审查：修了没有描述的 Shell 命令可能把 ghp_… 之类的值当标签显示的问题，修了带反斜杠的网址显示成错误 host 的问题，修了嵌套 find -exec 和大量 << 让单次调用卡住数秒的性能问题，并新增 commandStations（社区贡献）
  • 提交： 共约 120 次提交、17 位贡献者（alexeyw 96 次为主），近 7 天约 63 次，近 24 小时 13 次，最新一次 11-22 02:49 北京时间；方向集中在 Shell 命令解析的正确性、安全加固和多语言
  • Issues： Issue 共 21 个、目前只开放 1 个（还是作者自己记的 kitty 帧率限制）；PR 122 个、已合并 118 个。维护者响应很快且认真：#81（iTerm2 图片模式内存暴涨到 17 GB）报告后 24 分钟回复、1 小时内复现，当晚发 0.9.0 先关掉 iTerm2 图片，并向 iTerm2 报 bug，对方在 3.7.8 修复后再测量恢复；#69（VS Code on Windows 不显示）16 分钟内关闭；用户提的功能请求（如 #97、#98、#103）多在一到三天内实现

快速上手

  1. 在 Claude Code 终端会话里输入 /plugin install lot-map --marketplace alexeyw/lot-map，回答 y 添加 marketplace 并选作用域；提示找不到时先在 shell 里执行 claude plugin marketplace add alexeyw/lot-map，再 claude plugin install lot-map@lot-map。桌面 App 里点输入框旁的 + → Plugins → Add marketplace
  2. 新开会话，面板会自动打开；终端里需要至少 144 列，否则输入 /lot-map。想在终端看到地图：echo '{"terminalView":"braille"}' | claude plugin configure lot-map@lot-map --values-stdin，并用 /tui fullscreen 或 CLAUDE_CODE_NO_FLICKER=1 claude 启动全屏渲染
  3. 想看每次调用吃多少上下文，再打开 contextCost：echo '{"contextCost":"true"}' | claude plugin configure lot-map@lot-map --values-stdin。更新时先 claude plugin marketplace update lot-map 再 claude plugin update lot-map@lot-map

风险与注意点

  • 只服务 Claude Code： 不支持 Codex、Cursor 等其他 Agent；作者只在 macOS + Claude Code 2.1.321 上测试，Windows/Linux 是用户反馈能用
  • 很新、单人主力： 建库 12 天，9 天里从 v0.5.3 发到 v0.13.1，选项和行为还会变；96/120 次提交来自作者一人
  • 更新直接跟 main 分支： 从这个仓库加的 marketplace 跟随 main，更新会拉下当时 main 上的任何代码；插件能拿到每次调用的完整输入（含命令行、写入文件的内容），在意的话更新前先看 diff
  • 团队/企业账号： 组织策略可能跳过它的 hook 并在对话里反复提示，需要关掉 guardedHooks，代价是少了 Hooks 站点等信息
  • 终端图片坑： iTerm2 3.7.8 以下图片模式会让内存暴涨（已自动关闭），kitty 帧率有上限；contextCost 只是估算
