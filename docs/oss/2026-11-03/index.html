Floorplan：让 Claude Code / Codex 读完你的代码，画出一张能点、能问、能体检的应用地图

今天值得试：用 AI 写出来的应用常常「能跑，但说不清怎么跑的」。Floorplan 装成 Claude Code 或 Codex 插件，一句「Make me a floorplan of this app」就生成一张本地交互地图：每个模块、文件、接口都配一句大白话说明，前端请求连到对应的后端接口（跨仓库也行），还附带一份针对 AI 写的代码的安全体检。北京时间今天凌晨 04:07 刚发 v0.6.3。

仓库：haydenschmitty/floorplan · 在线演示

解决什么 / 适合谁

靠 Claude Code、Codex 写应用、自己不太读代码的人，想搞清楚「下单时发生了什么」「改这张表会坏哪里」；团队给新人讲架构；以及每次让 AI 改完代码后想看清它到底动了哪些地方的人。MIT，纯 Node 脚本、零依赖。

README 里的要点

  • 地图可逐层放大：整个应用 → 模块 → 文件组 → 文件 → 接口，每层都显示谁用它、它用谁；默认大白话，一键切到开发者视角。
  • 从页面出发：选一个页面，看它背后的组件、请求、服务端代码、数据和外部服务。
  • 对地图提问（Ask 栏）：如「退款怎么到客户卡上」，返回答案加只含相关部分的小地图和分步讲解；走你自己的 Claude Code CLI 或 Codex 登录，不需要 API Key，且只读代码不改代码。
  • 健康检查：找代码里或发到浏览器的密钥、谁都能读的 Supabase 表、开放的 Firebase 规则、能被伪造的 Stripe webhook、没登录校验的接口，每条附可直接粘贴的修复提示。作者明说这是检查不是审计。
  • Recent work：AI 刚改过的卡片标绿，并写明每处改动和你需求的关系；「Update the floorplan」只重读变动部分。
  • 还能从 PRD 画「蓝图」，规划尚未写的系统。支持 TS/JS/Python/Go/Rust/Java/Kotlin 等，以及 Express、FastAPI、Django、Next.js、Gin、Axum、Spring 等框架的接口识别。
  • 只在项目里写一个 floorplan/ 文件夹（自动 git 忽略），本地小服务器只接受本机连接，无分析统计。

近期活跃证据

  • Issues：10-28 至今共约 35 个，大多当天关闭。一位用户 11-02 一口气报了 13 个健康检查误报（#40–#52），作者当天全部回复并在 v0.6.2 修掉；仍开放的有 ASP.NET Core 支持（#27）、Ask 栏在 MCP 服务器很多时报「Prompt is too long」（#66）等。外部 PR 已合入十余个。
  • Release：10-27 建库以来共 22 个版本，最新 v0.6.3（北京时间 11-03 04:07），新增识别「方法+路径」路由表、Fastify 前缀和 Django include 前缀；v0.6.2 大幅减少健康检查误报并加了「Not a problem」按钮。
  • 提交：共 120 次，作者 99 次，另有 5 位贡献者；每天都有提交，11-02 一天 25 次，方向是更多框架的接口识别和降低误报。

快速上手

  1. 准备 Node.js 18+ 和 Claude Code（或 Codex）。
  2. Claude Code 里运行 claude plugin marketplace add haydenschmitty/floorplan 和 claude plugin install floorplan@floorplan；Codex 用 codex plugin marketplace add haydenschmitty/floorplan 加 codex plugin add floorplan@floorplan。
  3. 在项目目录开新会话，说「Make me a floorplan of this app」，地图会自动在浏览器打开；改完代码后说「Update the floorplan」。

风险 / 注意点

  • 首次建图会让 Agent 描述每个文件和接口，大项目耗时长、吃你的 Claude/ChatGPT 额度。
  • 健康检查仍在快速调规则，误报不少，别当成正式安全审计。
  • 项目刚一周、作者单人主力；C#、PHP 等语言暂不支持；Windows 上 Ask 栏曾有问题（#20 已修）。
