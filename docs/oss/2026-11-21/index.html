AI Agent模型本地推理个人助理

Linger：把「个人 AI 助理 + Agent 团队」整套搬到自己电脑上，本地模型跑，零 token 费

为什么今天值得试： 多数「个人 Agent」要么全靠云端 API 计费，要么只是一个聊天壳。Linger 是一套能自托管的完整个人 Agent 工作台：自带 MoE 推理引擎 PolyStrata，把模型里最常用的专家放在显卡上、其余放内存/SSD，官方说 125B 的 Qwen3.8-Flash-Next 能在 12 GB 显卡 + 64 GB 内存上跑；在这之上有每晚自动整理的 Wiki 记忆、会主动提醒的「Another Me」、桌面/浏览器操作和多 Agent 团队。北京时间 11-21 01:57 刚发 desktop-v0.1.6（加了简体中文界面、免 Key 的 DuckDuckGo 网页搜索、Antigravity 运行时），11 天发了 7 个桌面版。

  • 仓库：https://github.com/simplexai-labs/linger
  • 官网/文档：https://heylinger.com 、https://docs.heylinger.com/
  • 许可证：Linger Open Source License（基于 Apache-2.0 加附加条件，见下方风险）；主语言 TypeScript（服务端有 Go）；2919★ / 269 fork；最新 desktop-v0.1.6（2026-11-21 01:57 北京时间）
  • 出品方：SIMPLEX AI TECHNOLOGIES PTE. LTD.；2026-11-10 11:50 北京时间建库

解决什么问题、适合谁

  • 想要一个「记得你的事、会主动跟进」的个人助理，但不想把邮件、聊天、会议数据交给云服务的人
  • 手上有一张 8–24 GB 的 N 卡或 16 GB 以上内存的 Apple 芯片 Mac，想看看本地模型能把 Agent 跑到什么程度的人
  • 已经在用 Claude Code / Codex / Pi，想把它们接进一个有共享记忆、团队协作、审批流的工作台的开发者

README 里的关键能力

  • 本地大模型（PolyStrata）： MoE 专家分层放在 GPU / 内存 / SSD，常用的专家自动上移到显卡；README 表里 RTX 3060 12 GB 上 Qwen3.8-Flash-Next 写作约 45.5 tok/s，8 GB 笔记本 4070 约 38.1 tok/s（Q2_0，实验室在大卡上限制显存模拟测得）
  • Model Autopilot： 一条命令检测显卡、内存和带宽，只保留能放下至少 64K 上下文的模型，选最聪明、再选最快的，装完要真答对一个问题才算装好；README 按机器档位给出推荐（如 Mac 24 GB → Qwen3.8-27B，Linux 8 GB 卡 + 32 GB → Qwen3.6-35B-A3B）
  • Wiki 与记忆： 「Another Me」回读收件箱，每晚把邮件、聊天、会议整理成所有 Agent 都能搜的 Wiki 页面，数据留在本机
  • 主动的 Another Me： 盯着收件箱、日历、Slack，只在需要你时才发消息；每晚「Dreaming」根据你对它消息的反应改写决策规则（被拒两次就闭嘴，被催两次就立刻说），不重新训练模型
  • 更多： 在 Mac/Windows/Linux 桌面上操作 App、在你已登录的 Chrome 里干活；多 Agent 共用一份 team.md；长任务交给后台分身；所有 Agent 共享本地模型并让你等着的活优先；可接 Claude Code、Codex、Pi（0.1.6 起加 Antigravity），走本地模型或你自己的订阅/Key；会议录音实时转写

近期活跃证据

  • Release： 北京时间 11-10 发 desktop-v0.1.0，到 11-21 01:57 的 v0.1.6 共 7 个桌面版。v0.1.6 加了中英文界面实时切换、内置网页搜索（默认 DuckDuckGo，可填 Tavily/Brave/Exa 等 Key）、Antigravity 运行时、Outlook 日历连接器、Windows x64 的 PolyStrata 支持，修了 Windows 管理员账户安装、Unicode 路径、Pi 的 shell/MCP 调用绕过权限审核等问题；12 位贡献者参与，其中 6 位首次贡献
  • 提交： 共约 686 次提交、18 位贡献者（LeoXing1996 119、jeffrey-bin 107、oldwinter90 102、NightRain233 99、muterC 94），近 7 天约 470 次，北京时间 11-20 当天 142 次，最新一次 11-21 00:00 北京时间，主要在做界面汉化和桌面版安装修复
  • Issues： Issue 共 49 个、开放 18 个；PR 351 个、已合并 279 个。新 Issue 集中在 Windows 安装（CUDA 检测、目录权限、中文用户名路径导致 PostgreSQL 初始化失败）和 Codex Agent 经常报「没把回复发到 Room」；维护者回复很具体，比如 #329 当天用中文一步步带用户查日志、#344 讨论到 macOS TCC 签名细节并当天合并文档修正

快速上手

  1. 在 Releases 下载对应安装包：macOS（Apple 芯片、14.0+）的 .dmg、Windows 的 -setup.exe（或免安装 zip）、Linux 的 .tar.gz（glibc 2.35+），并用 SHA256SUMS.txt 校验
  2. macOS 首次启动前在终端执行 xattr -dr com.apple.quarantine /Applications/Linger.app（包未公证）；Windows 遇到 SmartScreen 点「更多信息 → 仍要运行」
  3. 打开后在设置页点 Quick Install，按提示让它检测硬件、装本地模型；不想下大模型就在 Settings → Models 填自己的 API Key，或选 Claude Code / Codex / Pi 作运行时。多台电脑共用可改用 docker compose up --build --detach --wait 自托管（至少 5 GiB 内存）

风险与注意点

  • 很新、还在 0.1： 建库 11 天，开放 Issue 里不少是 Windows 安装直接失败；安装包没签名/公证，macOS 自动更新后屏幕录制权限可能失效，需要手动重置
  • 性能数字要打折看： README 速度和「≈ Claude Opus/Sonnet」的对比多数是官方实验室在大卡上限制显存模拟出来的，并说明真实同档机器可能更慢；12 GB 卡跑 125B 那档首 token 约 3 分钟，且不是该档的默认推荐
  • 权限很大： 它会读你的邮件、日历、Slack，能在已登录的 Chrome 和桌面 App 里点按、发邮件，建议先在测试账号上跑，保留发信前审批
  • 许可证不是纯 Apache： 不得未经授权把 Linger 当托管服务提供给组织外的人，用前端时不得去掉 Logo 和版权信息；贡献者还要同意出品方可随时调整许可证、把贡献用于商业
  • Docker Compose 默认测试密码： 示例 owner 账号密码是 test1234，开放给别人访问前一定要改
