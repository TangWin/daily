2. Problem it solves / who it’s for

Developers who want a local autonomous agent that actually drives the machine (browser with login sessions preserved, terminal/files, mouse/keyboard/vision, mobile via ADB), and that gets better over time by turning solved tasks into reusable Skills/SOPs — without adopting a heavy multi-service harness. Especially attractive if you care about token efficiency (README claims <30K context vs 200K–1M peers) and a try-it path that is clone + API key + TUI.

3. Key capabilities / usage (from FULL README)

Read full bilingual README (~803 lines) from gh api repos/lsdefine/GenericAgent/readme.

Design: “don’t preload skills, evolve them.” Core ≈ 3K LOC, ~100-line Agent Loop (agent_loop.py), 9 atomic tools.

Atomic tools: code_run, file_read, file_write, file_patch, web_scan, web_execute_js, ask_user, update_working_checkpoint, start_long_term_update.

Memory layers L0–L4: Meta Rules → Insight Index → Global Facts → Task Skills/SOPs → Session Archive.

Computer control: TMWebdriver = real Chrome/Chromium + extension (cookies/login preserved); claims strong bot-detection pass rates in README tables; computer-use / OCR / vision unlocked by *telling the agent* to set them up from SOPs in memory (not by reading long docs).

Frontends: TUI (frontends/tui_v3.py recommended EN), Streamlit (launch.pyw), Desktop portable, IM bots (Telegram/Discord/Lark; CN section also WeChat/QQ/WeCom/DingTalk).

Models: Claude / Gemini / Kimi / MiniMax etc. via mykey.py.

Self-evolution: new task → explore/install/debug → crystallize Skill → recall next time (WeChat read, HN digest, stock monitor, Gmail send examples).

Extras in README: Goal / Goal Hive / Morphling / Conductor modes; Datawhale tutorial; Skill Hub (Sophub); community GUIs.

5. Quick start (1–3 steps)

  1. git clone https://github.com/lsdefine/GenericAgent.git && cd GenericAgent
  2. uv venv && uv pip install -e ".[ui]" then cp mykey_template_en.py mykey.py and fill LLM API key
  • Require Python 3.11 or 3.12 (README: do not use 3.14 / pywebview issues)
  1. Launch: python frontends/tui_v3.py (TUI) or python launch.pyw (Streamlit)
  • Optional one-liner installers in README (ga_install.sh / .ps1); then tell the agent e.g. *“Set up your web automation capability.”* / *“Probe this system and set up your computer-use capability.”*

6. Risks / caveats

  • Full system control — runs code, drives browser/OS with user permissions; not a sandbox (similar risk class to coding agents).
  • Last core commit ~4 days ago (2026-09-14) — still within 2 weeks, but quieter than omnigent/prime-agent’s daily merge firehose.
  • Desktop release lag — portable Desktop tag is Aug 24; for latest behavior prefer git pull + Python path.
  • Windows TUI flaky — README recommends Git Bash; some open desktop/session bugs (#806, #809).
  • SOP language — preinstalled SOPs Chinese-first (agent can rewrite to English on request).
  • Official channel disclaimer — only GitHub + gaagent.ai; DintalClaw sole authorized commercial partner.
