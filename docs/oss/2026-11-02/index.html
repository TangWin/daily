Kanzo：一个 4.5 MB 的小程序，同时是浏览器里的看板和给编程 Agent 用的 MCP 服务器，你和 Claude Code / Codex 在同一块板上分任务

今天值得试：同时开好几个编程 Agent 时，最乱的是「谁在做什么」。Kanzo 不用注册、不用服务器，跑一条 kanzo 就有看板，Agent 通过 MCP 自己领任务、挪卡片、写进度评论。北京时间今早 04:21 刚发 v0.3.0，新增多台电脑共享同一块板和 Windows 原生支持。

仓库：emanuele-em/kanzo

解决什么 / 适合谁

天天用 Claude Code、Codex 等 Agent 写代码、想把任务排队交给它们并随时看进度的开发者；也适合几台电脑（或一台树莓派）上跑多个 Agent、想共用一个任务池的人。Rust 写的，AGPL-3.0。

README 里的要点

  • 三个入口：浏览器里的看板（给你）、MCP（给 Agent）、kanzo 命令（给终端和脚本）。从不需要手改文件，数据全在 ~/kanzo/kanzo.db（SQLite）。
  • 接 Agent 只要一行：claude mcp add kanzo --scope user -- kanzo mcp 或 codex mcp add kanzo -- kanzo mcp；其他客户端可用 http://localhost:4242/mcp。然后说「从 kanzo 领下一个任务去做」，Agent 会把卡片挪到 doing 并边做边评论。它根据当前仓库的 git remote 自动找到对应项目。
  • 标记为 Human 的任务 Agent 不碰，Agent 也能把任务交还给你；可开 Backlog 列存放还不想让 Agent 动的想法。
  • 多机两种方式：kanzo share on / kanzo join <ip> 局域网或 VPN 实时共享一块板；或用你自己的私有 git 仓库 kanzo sync 同步。
  • 很省：程序 4.5 MB，空闲内存 4.5 MB，Agent 的工具清单约 900 token，每次回复 10–60 token。还有 kanzo export 导出 Markdown/JSON、kanzo service install 开机自启。

快速上手

  1. 安装：curl -LsSf https://github.com/emanuele-em/kanzo/releases/latest/download/kanzo-installer.sh | sh（或 cargo install kanzo）。
  2. 运行 kanzo，浏览器打开 http://localhost:4242，按 n 加几个任务。
  3. claude mcp add kanzo --scope user -- kanzo mcp，重启 Claude Code 后说「从 kanzo 领下一个任务去做」。

风险 / 注意点

  • 才一周大（v0.3.x），基本是单人项目，用户量还小，问题可能没暴露完。
  • 共享看板没有任何登录鉴权，share on 会把看板开放给整个网络，只在信任的局域网或 VPN 里用。
  • 安装方式是 curl | sh，介意的话先下载产物并用 gh attestation verify 校验，或走 cargo。
  • AGPL-3.0：改了之后通过网络对外提供服务需要开源修改。
