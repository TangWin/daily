rea-video：把任意视频逐镜拆成「怎么拍 / 怎么生成 / 怎么写代码」，再给你复刻方案

为什么今天值得试： 10 月 30 日（北京时间）开源，一周多冲到约 3000 星；今天上午 09:49 还在合「影视片段」新类别。实拍、AI 片、数字人、3D、代码动效、录屏混剪都能拆，离线工具 alone 在原始文件上准确率就很高，适合想搞清「这条爆款到底怎么做的」再低成本复刻的人。

仓库：JuneYaooo/rea-video

它解决什么问题 / 适合谁

刷到一条抖音 / TikTok / 产品片，不知道是实拍、AI、代码动效还是混剪，更不知道该怎么照着做一条。一键复刻工具（如 Hypit）直接重做，但不会告诉你原片几个机位、怎么打光、字幕节奏和配乐 BPM。rea-video 先做逆向：逐镜判定制作方式、给证据，再输出拍摄方案 / 反推提示词 / Remotion 思路。

适合：做短视频与带货的创作者、研究 AI 视频工作流的人、以及已经在用 Claude Code / Codex 的开发者。思路来自已推过的 morluto/rea，但这是专门打视频链路的产品。

从 README 读到的要点

  • 覆盖面广： 实拍（口播、桌拍、探店）、AI 视频、数字人对口型、3D/动画、代码/模板动效、录屏、混合混剪；除画面外还拆字幕花字（可导出 SRT/ASS）、贴纸画中画、剪辑节奏、人声/配乐/音效。
  • 给 Agent 用： 在 Claude Code / Codex 里说「安装仓库，然后拆这条视频：/path/to/video.mp4」即可；也可 装 CLI + skill。需要 ffmpeg 与 Python 3.10+。
  • 输出三件套： 一句话结论（如「AI 41% + 代码界面 59%，曲库 122 BPM」）、按实拍/AI/代码分开的复刻方案、完整 （逐镜截图、证据、提示词、拍法与声音）。
  • 看图模型可选： 工具离线免费；平台转码片建议加 Gemini / 豆包或能看图的 agent，准确率可回到约 99%。换元素复刻可接 cheap-claude-video。
  • 自测数字： 调参集/留出集上工具 alone 约 98–99%；公众号转码片工具 alone 约 88%，加看图与 agent 复核可到约 100%。镜头切点全对。

近期活跃证据

  • Issues： 约 5 个 Issue，开放 2（含「求拆解」模板）；维护者对求拆解会贴出完整逐镜结论与复刻步骤，对判错类 bug（#4/#5）当天关闭并修规则。
  • Release： 尚无正式 GitHub Release，以 main 持续迭代为主。
  • 提交： 约 57 次提交（作者 JuneYaooo 约 51）；北京时间今天 09:49 仍在加「影视片段」类别与黑边/帧率线索规则，近几天密集修 AI/实拍误判与代码渲染镜头时间轴。

怎么快速上手

  1. 装好 与 Python 3.10+，在 Claude Code / Codex 里说：安装 ，然后拆解你的 。
  2. 或手动： 后跑 ，再执行 按 CLI 文档跑。
  3. 平台下载的压缩片建议把 Gemini / 豆包等接口告诉 agent；看完 再决定实拍、生成还是写 Remotion。

风险与注意

  • 没有正式 Release： 安装与行为以 main 为准，升级可能有破坏性变化。
  • 单人主力早期项目： 贡献集中在作者；Issue 少但质量高，社区仍在起步。
  • 版权与合规： README 明确禁止直接搬运他人画面/音乐/肖像；投放需遵守平台与当地 AI 标识规则。复刻实拍段仍要你自己拍。
  • 转码片更吃看图： 抖音等平台下载后噪点证据丢失，工具 alone 可能把实拍手机屏判成 3D/AI，需要看图复核。
