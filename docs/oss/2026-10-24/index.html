OpenFilm：让编程 Agent 直接做视频，你再在真编辑器里改

今天值得试，是因为它把「AI 生成视频」变成了 Agent 最擅长的事：写网页。Claude Code / Codex 写出一个 film.html，本地 Studio 里实时看成片，再手动或用一句话改任何细节，导出 MP4 或剪辑工程。

仓库：openfilm/openfilm（MIT，TypeScript，约 2.3k★，2026-10-04 北京时间建库）

解决什么 / 适合谁

  • 想用编程 Agent 做产品宣传片、发布视频、讲解动画、数据动画的开发者和独立开发者
  • 受够了「一句话生成视频」不可控、不能精修的人：这里每一帧都是可改的网页和时间线上的片段

README 里的关键点

  • 一个 HTML 文件：film.html 里每个 <section> 是一条轨道，片段就是元素（页面、视频、图片、声音），用 #t=12,18 指定片段、at 指定起点、CSS 管位置和样式
  • 一个函数：每个镜头是一个网页，实现 frame(t) 画出任意时刻；three.js、WebGL、canvas、SVG、GSAP 都能用，不需要 Remotion 这类框架。唯一规则是同一个 t 必须画出同一张图
  • 真编辑器 Studio：在 Chromium 浏览器里本地运行，可拖动/缩放/改文字和颜色、在时间线上剪切，改动写回文件让 Agent 接着改；可存命名版本，导出视频、GIF、字幕、透明视频，以及给 Final Cut Pro、Premiere Pro、DaVinci Resolve 的时间线
  • 质检：openfilm look 用两种乱序各画一遍帧，标出不一致的帧、页面报错、字体加载失败、缺失音频、被裁掉的文字
  • 命令：open、look、render（支持 --4k、--blur、--alpha）、get（配音、音乐、音效、图片、视频，用你自己的 ElevenLabs/OpenAI/Google/fal 等 key）、doctor
  • 制作、编辑、渲染都不需要账号；另有 macOS/Windows 桌面版，自带 ffmpeg 和无头浏览器，旁边带聊天面板可接 Claude Code、Codex 等 Agent

近期活跃证据

  • 提交：10-01 以来 120 次提交、19 位贡献者（PazChen 69 次为主力），最新提交 10-23，方向集中在导出速度、Windows 兼容、快捷键方案和更多 Agent 接入
  • Release：已发 11 个版本，最新 v0.2.5（2026-10-22 06:25 北京时间），导出快 2–4 倍、更省磁盘、颜色保真，新增 DeepSeek Harness 接入，音量改为 dB
  • Issues：10-01 以来新建 37 个、已关 26 个；维护者回复具体，如 #104 4K 渲染吃满内存在 0.2.1 改为按空闲内存分配后关闭，#181 长片渲染卡住维护者 10-23 确认根因并邀请 PR，社区当天已提交修复；累计合入 118 个 PR

快速上手

  1. 装好 Node 22.2+ 和 ffmpeg，在 Agent 里运行 npx skills add openfilm/openfilm
  2. 对 Agent 说：「给我的 CLI 做一个 20 秒带音乐的发布视频」，它会在 Studio 里打开成片
  3. 或者先打开现成示例：npx -y openfilm@latest open https://github.com/openfilm/examples/tree/main/one-prompt

注意点

  • 首次运行会下载约 100MB 无头 Chromium；预览和导出建议用 Chrome/Edge
  • 配音、音乐、AI 图像和视频要自己接服务商 key，会产生费用
  • 项目才 3 周，版本迭代很快；Windows 有几个未解决问题（#198 安装器报错、#190 DeepSeek Harness 无法启动），长片渲染卡住问题 #181 修复尚未合入
  • 主力开发者集中在一人，名称和 Logo 有商标限制（代码是 MIT）
