Talorys：一条命令，在你自己的 Cloudflare 账号里养一个私人 AI 助理

今天值得试，是因为它把「私人 Agent」做得很轻：不用租服务器、不用数据库，npx create-talorys@latest 一条命令就部署到你自己的 Cloudflare 免费额度里，聊天、记忆、待办、笔记、定时提醒全都有，数据只存在你的账号里，作者那边什么都不收。这两周社区 PR 合得很勤，维护者今天还在开远程 MCP 工具接入的 PR。

仓库：rociiu/talorys

解决什么 / 适合谁

想要一个随时能用、手机电脑都能开的私人助理，但不想把记忆和待办交给第三方 SaaS，也不想自己运维 VPS 的人。单用户设计，没有注册、没有团队功能。

README 里的关键点

  • 架构：Pages 前端 + 一个没有公网地址的私有 Worker（只通过 service binding 访问），所有数据放在一个 SQLite 版 Durable Object 里；模型默认是 Workers AI 的 @cf/zai-org/glm-4.7-flash，流式输出加工具调用。
  • 记忆可查看、编辑、删除，每轮只带最相关的几条；可选语义召回（默认关），还有「记忆历史」，比如你说卖了车，它会问旧事实是不是该标为过去。
  • 待办/笔记/项目可在界面增删改，也能聊天里直接说；「AI 任务规划」先出一张可编辑的计划卡，你确认后才一次性创建。
  • 自动化：一次性/循环提醒、每日待办摘要、可选 AI 例行任务，靠 Durable Object 闹钟触发，支持 Web Push 推到手机和电脑。
  • 安装器会让你设主人密码（本地 PBKDF2 哈希，只存为 Cloudflare secret），中断了重跑会续上、不删数据；还有 update、doctor、reset-password。
  • 设置里有输出 token、上下文、每日 AI 请求次数等上限，用量面板会估算 Neurons 和美元；AI 额度用完时提醒和笔记照常可用。
  • 有个人访问令牌，外部脚本和其他 AI 助手能调它的 API；备份导入当作不可信数据处理，新导入的自动化默认暂停。

近期活跃证据

  • 提交：2026-10-10 建库至今约 137 次提交、13 位贡献者（rociiu 49、who 30、rudycelekli 27），最近一批修复在 10-26 早上（北京时间）合入，比如时区相关的提醒默认时间、嵌套任务勾选、备份导入不覆盖本地新改动；82 个 PR 已合入。
  • Release：最新是 create-talorys@0.1.7（10-19 08:20 北京时间），加了个人访问令牌、Web Push 通知、按语义查找任务/笔记/自动化、自动化可编辑。
  • Issues：共 12 个，关了 7 个，bug 基本 1 天内处理（如 #15 删不掉任务、#31 出现两个聊天框）；语义检索提案 #44 里维护者逐条给出实现约束，贡献者照着做完并合入，讨论质量很高。MCP 需求 #1 已有社区 PR #42，维护者今天又开了 #102 来做这件事。

快速上手

  1. 装好 Node.js 22+，有一个 Cloudflare 账号（免费版即可）。
  2. 运行 npx create-talorys@latest，浏览器里授权 Cloudflare，设主人密码，等它打印 https://….pages.dev 地址。
  3. 打开地址登录，试试「明天 9 点提醒我交周报」「帮我规划下个月上线 App 的任务」。只想本地看看的话，clone 后 npm install && npm run dev，用模拟 AI，不需要 Cloudflare 登录。

注意点

  • 你的聊天和相关记忆会交给 Cloudflare Workers AI 做推理，隐私是「不经开发者」而不是「不出你的电脑」。
  • 免费额度不是无限：Workers AI 有每日 Neuron 配额，账号如果在付费计划上，超出部分会由 Cloudflare 计费；默认模型是轻量的 GLM-4.7-flash，复杂任务能力有限。
  • 还很早期（0.1.x），远程 MCP 工具、联网搜索都还在 PR/提案阶段；npm 上的安装器自 10-19 后还没发新版，main 上的新修复要等下次发版或自己从源码部署。
