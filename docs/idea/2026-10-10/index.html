  1. 目标用户

    坚持磁盘不落密钥 / GitOps / 1Password CLI，却被 coding agent 反复打断批准的开发者

    现有方案

    1Password CLI/op run, Vault, Doppler/Infisical, direnv, secret MCP

    现有方案的缺陷

    每次 op read 都要手表批准；agent 循环放大成本；开发者被迫写 .env 破坏安全模型

    解决方案

    Agent Secret Proxy：会话 TTL + 命令白名单注入，审计不写盘

    MVP

    CLI agent-secrets start --ttl 45m --allow 'pytest*,curl ...'

    用户原话 1 条
    Please write the 1Password creds to .env and use .env instead because I'm tired of clicking approve on my watch 15 times for every test run.来源 ↗

  2. 目标用户

    Stripe 订阅 SaaS indie/小团队，webhook 只接了 completed+deleted 的人

    现有方案

    Stripe Billing, Baremetrics/ChartMogul, dunning tools, Stripe Leak Check

    现有方案的缺陷

    教程默认 deleted=停权；payment_failed 过纠；webhook 乱序

    解决方案

    以 subscription.status 驱动权限 + 只读 key 审计风险金额

    MVP

    CLI stripe-access-audit 输出仍有权未付清单

    用户原话 2 条
    Only the first option ever sends customer.subscription.deleted. With the other two, the subscription sits there and your app never hears anything来源 ↗
    Stripe pays you net, but your books need gross. One payout mixes dozens of charges, fees, refunds来源 ↗

  3. 目标用户

    solo 对未来自己交接、小团队口头拍板写 ticket、Agent 一小时开干的 maker

    现有方案

    Linear/Jira, Notion 决策日志, PRD 模板, AGENTS.md

    现有方案的缺陷

    字段鼓励做什么而非触发例证；Agent 从短标题开写放大丢 why

    解决方案

    Trigger-linked Idea Brief，票只链 canonical，注入 Agent 前言

    MVP

    选中对话一键建 brief → Linear/GitHub 链接字段

    用户原话 2 条
    By the time a first version exists, the builder is working from that one line. The why is gone, so what ships is technically right and still misses the point来源 ↗
    don't log the decision, log the trigger… the actual example or complaint that made it obvious来源 ↗

  4. 目标用户

    卡在上传 payout/绑卡/接账户的 indie SaaS 与卖家工具作者

    现有方案

    PostHog 漏斗, Appcues, trust badge, 本地桌面工具

    现有方案的缺陷

    漏斗不区分财务承诺；无法解决文件离设备恐惧

    解决方案

    Trust-before-Ask：打码样例先于要权；本地/扩展预览

    MVP

    样例报告块 + 事件字典 + 可选 Shopify 扩展脚手架

  5. 目标用户

    实习/新教师与中小学老师，需要无声锁屏倒计时催收拾

    现有方案

    iOS 闹钟, Calendar Live Activity 类, 学校铃表

    现有方案的缺陷

    闹钟扰课；通用日历不懂收拾节点；课表导入麻烦

    解决方案

    Bell Schedule Live Activity + 学期模板

    MVP

    iOS 录入课表 → Live Activity；$4.99 买断试水
