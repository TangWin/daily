产品 Idea Top 5

  1. #1自托管软件会不会「翻车」：部署前先查作者前科、许可证和 API 变化，跑着的服务一旦开始锁接口、收订阅或换协议就提醒你，并给出迁移路线
  2. #2你用的云服务偷偷改了隐私政策：自动盯住备份、网盘、邮箱等服务的条款变化，用大白话告诉你改了什么、怎么退出，必要时帮你换成自己加密
  3. #3Apple Music 管不好本地音乐库了：一个尊重本地文件的 Mac 音乐管理器，批量改标签、整理合辑、查漏导入，再无损同步到 iPhone
  4. #4准备离开伴侣前，悄悄查清手机有没有被看：一步步检查共享账号、已登录设备、位置共享、描述文件和家里路由器，不惊动对方地完成断开
  5. #5试装 App 不留垃圾：安装前自动拍快照，决定不要时一键彻底回滚，连系统保护的缓存和设置项一起清掉
