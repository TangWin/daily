产品 Idea Top 5

11月28日RSS
  1. #1AI 编程工具和技能偷偷往外发了什么：装之前扫一遍会联网、会读登录文件的代码，装之后实时记下每个工具读了哪些密钥文件、把什么发到了哪台服务器，能拿给公司 IT 看
  2. #2Google Play、App Store 要公开个人开发者的电话和住址：帮你判断自己算不算「交易者」，配好能公开的商务地址和电话，按期完成两家商店的声明，别让 App 被下架
  3. #3AI 一年帮你做了几十个小工具，一半找不到：自动盘点散在聊天记录、各个仓库、别人电脑和部署平台上的项目，记下它是干什么的、在哪跑、怎么启动、还能不能用、花了多少 token
  4. #4你依赖的在线书和教程哪天突然没了：把收藏和常读的网页连同附带的代码、配置文件一起存到本地，原站一下线自动切到存档，还能整站从 Wayback Machine 拉回来离线看
  5. #5Mac 上能扛几十万封邮件的邮件客户端：本地建全文索引秒搜，所有操作都能用键盘和脚本完成，过滤规则直接写到服务器上生效
